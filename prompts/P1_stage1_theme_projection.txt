## Extraction rules

1. Each array item = one atomic canonical concept id (from catalog above).
2. Semantically similar expressions MUST map to the same id — never invent new ids.
3. If uncertain, still output the best-matching id instead of leaving empty.
4. Do not duplicate the same idea across benefits and drawbacks.
5. Do not infer unstated intentions — only what the student said or clearly implied in their words.
6. `topics`: 0–3 broader discourse tags (catalog ids or short snake_case labels, e.g. online_shopping).
7. `confidence`: your certainty that benefits/drawbacks lists are complete for what was said (0.0–1.0).
