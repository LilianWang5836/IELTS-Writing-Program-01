# 【Stage 2 共用】输出格式（非教学策略）

教学策略见各 Body 模块中的 `{{arbitrated_plan_json}}`。此处仅说明 JSON 字段与 slot 标签含义。

## Slot 标签（拆解用户原文时使用，按需选用）
| 标签 | 含义 |
|------|------|
| claim | 论点 / 分论点 |
| reason | 原因 / 机制 |
| elaboration | 论述展开 |
| support | 支撑 |
| example | 举例 / 场景 |
| link | 扣题 / 收束 |

`slots` 只填识别到的键；其余 `null`。`missing` 由系统 `coaching_signals_summary` 提供，勿自行推断 gap。

## logicBreakdown（有实质用户输入时可选填）
```json
"logicBreakdown": {
  "target": "body1 | body2",
  "chainSummary": "一句话概括",
  "slots": {},
  "missing": [],
  "userBlobSummary": ""
}
```

字符串单行，勿含未转义双引号。`advance` 永远 false。
